# 03. Type Casting and Print Formatting

## Type Casting

**Type casting** converts a value from one type to another: `str()`, `int()`, `float()`, `bool()`, `list()` and so on.

You cannot join a string and a number with `+`:

```python
# data_types.py
astring = input("Enter the string: ")
aint = int(input("Enter the integer: "))
print("Your string value is : " + astring)
print("Your number is : " + aint)
```

```console
  File "/root/lect5/data_types.py", line 4, in <module>
```

Cast the number to `str` first:

```python

print("Your string value is : " + astring)
print("Your number is : " + str(aint))
print("Your float number is : " + str(afloat))
```

## Five Ways to Format Output

| Style | Example |
|---|---|
| Concatenation with `+` | `"Name: " + name` (all parts must be strings) |
| Commas in `print()` | `print("Name:", name)` (adds a space, any type works) |
| **f-strings** (recommended) | `f"Name: {name}"` |
| `str.format()` | `"Name: {}".format(name)` |
| `%` formatting (old style) | `"Name: %s" % name` |

```python
# print_format.py
astring = "Ahmad"
aint = 54
afloat = 34.666

# 1. concatenation
print("Your string value is : " + astring + "\nYour number is : " + str(aint) + "\nYour float is : " + str(afloat))

# 2. commas
print("Your string value is :", astring, "\nYour number is :", aint)

# 3. f-string
print(f"Your string value is : {astring} \nYour number is : {aint} \nYour float is : {afloat}")

# 4. format()
print("Your string is {} \nYour number is {} \nYour float is {}".format(astring, aint, afloat))

# 5. % formatting
print("Your string is %s \nYour number is %d \nYour float is %f" % (astring, aint, afloat))
print("Your float rounded to 2 places is %.2f" % afloat)
```

| `%` code | Type |
|---|---|
| `%s` | string |
| `%d` | integer |
| `%f` | float (6 decimals by default) |
| `%.2f` | float with 2 decimals |

## Task 1: Swap Two Values

Read two values for `ali` and `kazim`, then swap them.

```text
Input:  ali = 5, kazim = 6
Output: ali = 6, kazim = 5
```

<details>
<summary><b>Solution</b></summary>

```python
# swap_values.py
ali = input("Ali: ")
kazim = input("Kazim: ")

temp = ali
ali = kazim
kazim = temp

print("Ali : " + ali)
print("Kazim : " + kazim)
```

```console
root@ahmadhassan:~/lect5# python3 swap_values.py
Ali: 5
Kazim: 6
Ali : 6
Kazim : 5
```

Python can also swap in one line: `ali, kazim = kazim, ali`.

## Task 2: Calculator

Read two numbers `x` and `y` and print their addition, subtraction, multiplication, division, modulus and exponentiation.

<details>
<summary><b>Solution</b></summary>

```python
# calculator.py
x = int(input("Enter the x number: "))
y = int(input("Enter the y number: "))

print("Addition       : x + y  =", x + y)
print("Subtraction    : x - y  =", x - y)
print("Multiplication : x * y  =", x * y)
print("Division       : x / y  =", x / y)
print("Modulus        : x % y  =", x % y)
print("Exponentiation : x ** y =", x ** y)
```
