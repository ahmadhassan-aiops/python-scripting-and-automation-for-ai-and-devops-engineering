# 09. Dictionaries

A **dictionary** stores data as **key: value** pairs. It is also called an associative array.

- Keys are **unique**; a duplicate key overwrites the old value.
- Dictionaries are optimized to find a value quickly when you know its key.
- Since Python 3.7, dictionaries keep the order in which keys were inserted.

```python
person = [12, 3, 5, 7]                  # list
person = (12, 4, 5, 6)                  # tuple
person = {12, 4, 5, 6, 7}               # set
person = {"name": "Ahmad", "age": 30}   # dictionary
```

Here `name` and `age` are **keys**; `"Ahmad"` and `30` are their **values**.

## Creating a Dictionary

```python
>>> dict1 = {uname: "ahmad"}
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'uname' is not defined
>>> dict1 = {"uname": "ahmad", "pass": "ahmad123"}
>>> print(dict1)
{'uname': 'ahmad', 'pass': 'ahmad123'}
>>> print(type(dict1))
<class 'dict'>
```

Keys that are text must be quoted; otherwise Python looks for a variable called `uname`.

## Reading Values

```python
>>> print(dict1["uname"])
ahmad
>>> print(dict1["Pass"])
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'Pass'
>>> print(dict1.get("pass"))
ahmad123
>>> print(dict1.get("Pass"))
None
```

**Interview question:** how do you avoid an error when a key may not exist?
Use **`get()`**: it returns `None` (or a default you pass, like `dict1.get("Pass", "not set")`) instead of raising `KeyError`.

**Interview question:** what is the difference between Python 2 and Python 3 dictionaries?
In Python 2 (and before 3.7) dictionaries did **not** keep insertion order, so printing could show keys in any order. In Python 3.7+ the order is preserved.

## Adding, Changing and Merging

```python
>>> person = {"name": "AH", "age": 30, "city": "Islamabad", "country": "Pakistan"}
>>> person["name"] = "Ahmad"
>>> person["salary"] = 1000
>>> print(person)
{'name': 'Ahmad', 'age': 30, 'city': 'Islamabad', 'country': 'Pakistan', 'salary': 1000}
>>> person.update({"company": "google"})
>>> print(person)
{'name': 'Ahmad', 'age': 30, 'city': 'Islamabad', 'country': 'Pakistan', 'salary': 1000, 'company': 'google'}
```

## Keys, Values and Items

```python
>>> print(person.keys())
dict_keys(['name', 'age', 'city', 'country', 'salary', 'company'])
>>> print(person.values())
dict_values(['Ahmad', 30, 'Islamabad', 'Pakistan', 1000, 'google'])
>>> print(person.items())
dict_items([('name', 'Ahmad'), ('age', 30), ('city', 'Islamabad'), ('country', 'Pakistan'), ('salary', 1000), ('company', 'google')])
```

## Copying

Just like lists, assignment shares the same dictionary; `copy()` makes a new one.

```python
>>> p1 = person
>>> p2 = person.copy()
>>> print(id(p1) == id(person))
True
>>> print(id(p2) == id(person))
False
```

## Removing Items

```python
>>> cred = {"uname": "AHMAD", "pass": "Ahmad@123", "server1": "192.168.1.1"}
>>> print(cred.pop("pass"))
Ahmad@123
>>> print(cred)
{'uname': 'AHMAD', 'server1': '192.168.1.1'}
>>> print(cred.popitem())
('server1', '192.168.1.1')
>>> print(cred)
{'uname': 'AHMAD'}
>>> cred.pop()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: pop expected at least 1 argument, got 0
>>> cred = {"uname": "AHMAD", "server1": "192.168.1.1"}
>>> del cred["server1"]
>>> print(cred)
{'uname': 'AHMAD'}
>>> cred.clear()
>>> print(cred)
{}
```

`popitem()` removes the **last inserted** pair (not a random one) and takes no argument.

## Building Dictionaries

```python
>>> keys = ["one", "two", "three"]
>>> values = [1, 2, 3]
>>> print(dict(zip(keys, values)))
{'one': 1, 'two': 2, 'three': 3}
>>> print(dict.fromkeys(["a", "e", "i", "o", "u"], "vowel"))
{'a': 'vowel', 'e': 'vowel', 'i': 'vowel', 'o': 'vowel', 'u': 'vowel'}
>>> user = {}
>>> print(user.setdefault("username", "AH"))
AH
>>> print(user.setdefault("username", "XYZ"))
AH
>>> print(user)
{'username': 'AH'}
```

`setdefault()` adds the key only if it doesn't exist yet; otherwise it returns the existing value.

## min, max, sum and sorted

```python
>>> nums = {1: 3, 5: 10}
>>> print(max(nums), max(nums.values()))
5 10
>>> print(min(nums), min(nums.values()))
1 3
>>> print(sum(nums), sum(nums.values()))
6 13
>>> print(sorted({"username": "AH", "password": "x", "AH": "y"}))
['AH', 'password', 'username']
```

These functions work on the **keys** unless you pass `.values()`.

## Task

From the nested dictionary below, print the PR and DR addresses.

```python
myinfo = {
    "server1": {
        "IBM": {
            "datacenter": "Islamabad",
            "env": {"PR": "192.168.1.1", "DR": "192.168.1.2"}
        }
    }
}
```

```text
Islamabad datacenter PR address is : 192.168.1.1
Islamabad datacenter DR address is : 192.168.1.2
```
