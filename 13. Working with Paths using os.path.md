# 13. Working with Paths using os.path

The `os.path` submodule inspects and builds file paths.

## basename(), dirname() and split()

```python
# os_path.py
import os
mypath = "/root/lect18/os_path.py"
print(f"My full path is {mypath}")
print(f"My base name is {os.path.basename(mypath)}")
print(f"My directory path is {os.path.dirname(mypath)}")
mylist = os.path.split(mypath)
print(f"My directory is {mylist[0]}")
print(f"My file is {mylist[1]}")
```

```console
root@ahmadhassan:~/lect19# python3 os_path.py
My full path is /root/lect18/os_path.py
My base name is os_path.py
My directory path is /root/lect18
My directory is /root/lect18
My file is os_path.py
```

On Windows the same code works with a path like `"C:\\Users\\Ahmad\\Desktop\\os_path.py"`.

## isfile(), isdir() and exists()

```python
# check_path.py
import os
mypath = "/root/lect19"
print(os.path.isdir(mypath))
print(os.path.isfile(mypath))

for path in ["/root/lect19", "/root/lect19/test1.txt", "/root/lecture-xyz"]:
    if os.path.exists(path):
        if os.path.isdir(path):
            print(f"{path} is a directory")
        else:
            print(f"{path} is a file")
    else:
        print(f"{path} is not valid, please type the correct path")
```

```console
root@ahmadhassan:~/lect19# python3 check_path.py
True
False
/root/lect19 is a directory
/root/lect19/test1.txt is a file
/root/lecture-xyz is not valid, please type the correct path
```

# link.py
import os
mypath = "/root/lect19/mylink.txt"
if os.path.islink(mypath):
    print(f"{mypath} is a link")
elif os.path.isfile(mypath):
    print(f"{mypath} is a file")

## join() and sep

Never glue paths with `+`. `os.path.join()` adds the right separator for the operating system.

```python
# join.py
import os
mypath = "/root"
child = "lect19"
print(mypath + child)
print(os.path.join(mypath, child))
print(os.path.sep)
```

```console
root@ahmadhassan:~/lect19# python3 join.py
/rootlect19
/root/lect19
/
```

On Windows, `os.path.join("C:\\Users", "Ahmad")` gives `C:\Users\Ahmad`.

## getsize(), normpath(), normcase() and samefile()

```python
# more_path.py
import os
print(os.path.getsize("/root/lect19/test1.txt"), "bytes")
print(os.path.normpath("/root//lect19/../lect19/./test1.txt"))
print(os.path.samefile("/root/lect19/test1.txt", "/root/lect19/mylink.txt"))
print(os.path.splitext("report.final.csv"))
print(os.path.abspath("test1.txt"))
```

```console
root@ahmadhassan:~/lect19# python3 more_path.py
17 bytes
/root/lect19/test1.txt
True
('report.final', '.csv')
/root/lect19/test1.txt
```

| Function | Does |
|---|---|
| `getsize(path)` | File size in bytes |
| `normpath(path)` | Cleans a path: removes double separators, `.` and `..` |
| `normcase(path)` | On Windows, lowercases the path and converts `/` to `\`; on Linux it returns the path unchanged |
| `samefile(a, b)` | `True` if both paths point to the same file (here the link points to `test1.txt`) |
| `splitext(path)` | Splits off the extension |
| `abspath(path)` | Turns a relative path into an absolute one |
