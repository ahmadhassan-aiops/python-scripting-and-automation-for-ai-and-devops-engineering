# 15. Command-Line Arguments with sys

The **sys** module gives access to the Python interpreter and its runtime: the version, the module search path, the arguments passed to the script, and a way to exit.

## Version and Search Path

```python
# sys_info.py
import sys
print(sys.version_info)
print(sys.path[:2])
```

```console
root@ahmadhassan:~/lect21# python3 sys_info.py
sys.version_info(major=3, minor=13, micro=16, releaselevel='final', serial=0)
['/root/lect21', '/usr/lib/python313.zip']
```

`sys.path` is the list of folders Python searches when you `import` a module.

## sys.exit(): Stop a Script

```python
# sys_exit.py
import sys
print("Ahmad")
print("Hassan")
print("sys exit start")
sys.exit()
print("Exit over")
```

```console
root@ahmadhassan:~/lect21# python3 sys_exit.py
Ahmad
Hassan
sys exit start
```

The last line never runs.

## sys.argv: Command-Line Arguments

`sys.argv` is a list: position 0 is the script name and the arguments follow.

```python
# arguments.py
import sys
print("This is the script name : " + sys.argv[0])
print("My full arguments are : " + str(sys.argv))
print("My total arguments are : " + str(len(sys.argv) - 1))
```

```console
root@ahmadhassan:~/lect21# python3 arguments.py AH Hassan Ali Ahmad
This is the script name : arguments.py
My full arguments are : ['arguments.py', 'AH', 'Hassan', 'Ali', 'Ahmad']
My total arguments are : 4
```

## Practical Example: Controlling a Service

Instead of asking for input, pass the action on the command line:

```python
import os
import sys
action = sys.argv[1]
os.system(f"systemctl {action} apache2")
```

Validate the arguments so the script explains how to use it:

```python
# sys_arguments.py
import os
import sys

if len(sys.argv) != 2:
    print(f"{sys.argv[0]} requires 1 positional parameter")
    print(f"Example : ./{sys.argv[0]} status OR start OR restart OR stop")
    sys.exit(1)

action = sys.argv[1]
os.system(f"systemctl {action} apache2")
```
