# 25. Working with JSON

**JSON** (JavaScript Object Notation) is a text format for structured data. It's everywhere in DevOps: API responses, configuration files, Terraform state, cloud CLI output.

| JSON | Python |
|---|---|
| object `{}` | `dict` |
| array `[]` | `list` |
| string | `str` |
| number | `int` / `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

Online viewers such as https://jsoneditoronline.org help you explore large JSON files.

import json

with open("os.json") as jf:
    data = json.load(jf)

    print(f"My dictionary is {item}")

print(data[1]["Version"])

## json.dump(): Dictionary to JSON File

```python
# dump.py
import json

myinfo = {
    "server1": {
        "IBM": {
            "datacenter": "Islamabad",
            "env": {"PR": "192.168.1.1", "DR": "192.168.1.2"}
        }
    }
}

with open("user_details.json", "w") as df:
    json.dump(myinfo, df)

with open("user_details_pretty.json", "w") as df:
    json.dump(myinfo, df, indent=4)
```

```console
root@ahmadhassan:~/lect35# python3 dump.py
```

```console
root@ahmadhassan:~/lect35# cat user_details.json; echo; cat user_details_pretty.json
{"server1": {"IBM": {"datacenter": "Islamabad", "env": {"PR": "192.168.1.1", "DR": "192.168.1.2"}}}}
{
    "server1": {
        "IBM": {
            "datacenter": "Islamabad",
            "env": {
                "PR": "192.168.1.1",
                "DR": "192.168.1.2"
            }
        }
    }
}
```

`indent=4` makes the file readable. To convert to and from **strings** (for example an API response), use `json.dumps()` and `json.loads()`.

## Task

From `fruit.json`, display the fruits that cost more than 1.

```console
root@ahmadhassan:~/lect35# cat fruit.json
[
  {
    "name": "apple",
    "color": "green",
    "price": 1.2
  },
  {
    "name": "banana",
    "color": "yellow",
    "price": 0.5
  },
  {
    "name": "kiwi",
    "color": "green",
    "price": 1.25
  },
  {
    "name": "grapes",
    "color": "purple",
    "price": 9.99
  }
]
```

```text
Total we have 3 fruits above price 1, and their names are : apple kiwi grapes
```

<details>
<summary><b>Solution</b></summary>

```python
# task.py
import json

with open("fruit.json") as jf:
    fruits = json.load(jf)

names = [f["name"] for f in fruits if f["price"] > 1]
print(f"Total we have {len(names)} fruits above price 1, and their names are : {' '.join(names)}")
```

```console
root@ahmadhassan:~/lect35# python3 task.py
Total we have 3 fruits above price 1, and their names are : apple kiwi grapes
```

Count the matching fruits with `len(names)`, not with the number of keys in one fruit.
