# 04. Escape Sequences and Comments

## Escape Sequences

An **escape sequence** is a backslash followed by a character that has a special meaning inside a string.

| Sequence | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Horizontal tab |
| `\\` | A literal backslash |
| `\b` | Backspace (deletes the previous character) |
| `\"` and `\'` | Quotes inside a string |

```python
# esc_character.py
print("\nAhmad")
print("\n\tHassan")

print("c:\\Users\\newfile")
path = "C:\\Users\\Ahmad\\Desktop\\DevOps\\Python\\Lecture \b6"
print(path)
```

```console
root@ahmadhassan:~/lect6# python3 esc_character.py

Ahmad

	Hassan
c:\Users\newfile
C:\Users\Ahmad\Desktop\DevOps\Python\Lecture6
```

- `\n` printed an empty line before each name, and `\t` indented `Hassan`.
- `\\` printed a single backslash, which is how Windows paths are written in Python strings.
- `\b` removed the space before `6`.

> **Raw strings** avoid escaping: `r"C:\Users\Ahmad"` keeps every backslash as typed.

## Quotes Inside Strings

```python
>>> print("My name is \"Ahmad\" Hassan")
My name is "Ahmad" Hassan
>>> print("""My name is "Ahmad" Hassan""")
My name is "Ahmad" Hassan
>>> print("My name is 'Ahmad' Hassan")
My name is 'Ahmad' Hassan
>>> print('My name is "Ahmad" Hassan')
My name is "Ahmad" Hassan
```

Using the same quote inside and outside without escaping is an error:

```python
string = 'My name is 'Ahmad' Hassan'   # SyntaxError
```

## Comments

Comments explain code and are ignored by Python.

### 1. Single-line comments start with `#`

```python
# comments.py
# print("This line is commented out")
print("c:\\Users\\newfile")   # a comment can also follow code
```

```console
root@ahmadhassan:~/lect6# python3 comments.py
c:\Users\newfile
```

### 2. Multi-line comments use triple quotes

A triple-quoted string that isn't assigned to anything works as a block comment (and as a **docstring** at the top of a function or file).

```python
# comments_multi.py
"""
path = "C:\\Users\\Ahmad"
print(path)
None of these lines run.
"""
print("Only this line runs")
```

```console
root@ahmadhassan:~/lect6# python3 comments_multi.py
Only this line runs
```
