# 06. String Operations

A **string** is a sequence of characters, written with single, double or triple quotes:

```python
"Ahmad Hassan"
'Ahmad Hassan'
'''Ahmad Hassan'''
"ahmad123@hassan"
```

## Indexing

Each character has a position. Counting starts at **0** from the left and at **-1** from the right.

```text
 A   L   I
 0   1   2     <- positive index
-3  -2  -1     <- negative index
```

```python
>>> name = "Ali"
>>> print(len(name))
3
>>> print(name[0])
A
>>> print(name[-1])
i
```

## Slicing

`string[start:end]` returns characters from `start` up to, but **not including**, `end`.

```python
>>> print(name[0:1])
A
>>> print(name[0:2])
Al
>>> print(name[0:3])
Ali
>>> print(name[0:])
Ali
>>> print(name[-1:])
i
>>> print(name[:-1])
Al
>>> print(name[-1:-3])
```

`name[-1:-3]` is empty because slicing moves left to right by default, and -1 is already to the right of -3.

## Concatenation and Repetition

```python
>>> fname = "Ahmad"
>>> lname = "Hassan"
>>> print(fname + lname)
AhmadHassan
>>> print(fname + " " + lname)
Ahmad Hassan
>>> print(fname, lname)
Ahmad Hassan
>>> print(f"My name is {fname} {lname}")
My name is Ahmad Hassan
>>> print(fname * 3)
AhmadAhmadAhmad
```

## Changing Case

```python
>>> name = "Ahmad Hassan"
>>> print(name.upper())
AHMAD HASSAN
>>> print(name.lower())
ahmad hassan
>>> print(name.casefold())
ahmad hassan
>>> print(name.capitalize())
Ahmad hassan
>>> name = "ahmad hASSAN"
>>> print(name.title())
Ahmad Hassan
>>> print(name.swapcase())
AHMAD Hassan
```

`casefold()` is like `lower()` but more aggressive for non-English letters, which makes it better for case-insensitive comparisons.

## Checking Content (Boolean Methods)

Methods that start with **`is`** return `True` or `False`.

```python
>>> name = "Ahmad"
>>> print(name.islower())
False
>>> print("ahmad".islower())
True
>>> print("AHMAD".isupper())
True
>>> print("12".isdigit())
True
>>> print(name.startswith("A"))
True
>>> print(name.endswith("d"))
True
```

## Counting and Searching

```python
>>> name = "ahmad"
>>> print(name.count("a"))
2
>>> print(name.index("a"))
0
>>> print(name.index("a", 1))
3
>>> print(name.find("m"))
2
>>> print(name.find("z"))
-1
>>> print(name.rfind("a"))
3
>>> print(name.index("z"))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: substring not found
```

| Method | Not found |
|---|---|
| `index()` | Raises `ValueError` |
| `find()` / `rfind()` | Returns `-1` |

The second argument is the position to start searching from. `rfind()` searches from the right.

## Strings Are Immutable

You can't change one character of a string, but you can delete the whole variable or build a new string.

```python
>>> name = "Ahmad"
>>> name[0] = "a"
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'str' object does not support item assignment
>>> del name
>>> print(name)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'name' is not defined
```

## Alignment and Padding

```python
>>> name = "AH"
>>> print(name.center(10, "*"))
****AH****
>>> print(name.ljust(6, "-") + "|")
AH----|
>>> print(name.rjust(6, "-"))
----AH
>>> print(name.zfill(10))
00000000AH
```

## Stripping Characters

`strip()` removes characters from **both ends**; `lstrip()` from the left and `rstrip()` from the right. With no argument it removes whitespace.

```python
>>> print(" Ahmad ".strip())
Ahmad
>>> print("*Ahmad*".strip("*"))
Ahmad
>>> print("Ahmad".strip("A"))
hmad
>>> name = "Ahmad Hassan Ahmad"
>>> print(name.strip("Ahmad"))
 Hassan 
>>> print(name.lstrip("Ahmad"))
 Hassan Ahmad
>>> print(name.rstrip("Ahmad"))
Ahmad Hassan 
```

> The argument of `strip()` is a **set of characters**, not a word. `strip("Ahmad")` keeps removing any of `A`, `h`, `m`, `a`, `d` from the ends until it reaches a different character, which is why the leading space survives in ` Hassan `.

## Splitting and Joining

```python
>>> name = "My name is Ahmad Hassan"
>>> words = name.split()
>>> print(words)
['My', 'name', 'is', 'Ahmad', 'Hassan']
>>> print(" ".join(words))
My name is Ahmad Hassan
>>> print("-".join(words))
My-name-is-Ahmad-Hassan
>>> print("Ahmad Hassan Islamabad Hassan Pakistan".split("Hassan"))
['Ahmad ', ' Islamabad ', ' Pakistan']
>>> path = "/root/admin/ahmad.txt"
>>> print(path.split(".txt")[0])
/root/admin/ahmad
>>> print("#".join("Ahmad"))
A#h#m#a#d
>>> print("\n".join("Ahmad"))
A
h
m
a
d
```

## Reversing

```python
>>> name = "Ahmad"
>>> print(name[::1])
Ahmad
>>> print(name[::2])
Amd
>>> print(name[::-1])
damhA
>>> print("".join(reversed(name)))
damhA
>>> print("*".join(reversed(name)))
d*a*m*h*A
```

`[start:end:step]`: a step of `2` takes every second character and `-1` walks backwards.

## Replacing and Sorting

```python
>>> text = "$Ahmad Hassan$ with$ symbols"
>>> print(text.replace("$", ""))
Ahmad Hassan with symbols
>>> print(sorted("Ahmad"))
['A', 'a', 'd', 'h', 'm']
```

Uppercase letters sort before lowercase ones because they have smaller character codes.
