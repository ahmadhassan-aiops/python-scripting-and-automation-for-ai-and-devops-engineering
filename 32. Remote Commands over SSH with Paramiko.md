# 32. Remote Commands over SSH with Paramiko

**Paramiko** is a Python implementation of the **SSHv2** protocol. It lets a script log in to remote servers, run commands and transfer files, the same things you do with `ssh` and `scp`, but automated.

It works in every direction, as long as the remote machine runs an SSH server:

| From | To |
|---|---|
| Windows | Linux |
| Linux | Linux |
| Linux | Windows |
| Windows | Windows |

## First Attempt: Unknown Host Key

```python
import paramiko
client = paramiko.SSHClient()
client.connect(hostname="192.168.1.11", username="ahmad", password="...")
```

```text
paramiko.ssh_exception.SSHException: Server '192.168.1.11' not found in known_hosts
```

Like `ssh` asking "Are you sure you want to continue connecting?", Paramiko refuses unknown servers. `AutoAddPolicy()` accepts them automatically (fine for a lab; in production, load known host keys with `client.load_system_host_keys()`).

## Running a Command

```python
import os
import paramiko

hostname = "192.168.1.11"
username = "ahmad"
password = os.environ["SSH_PASSWORD"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname=hostname, username=username, password=password)

stdin, stdout, stderr = client.exec_command("df -h")
print(stdout.read())
client.close()
```

```text
b'Filesystem                 Size  Used Avail Use% Mounted on\nudev                       1.7G     0  1.7G   0% /dev\ntmpfs ...'
```

`exec_command()` returns three file-like objects: **stdin**, **stdout** and **stderr**. `read()` returns **bytes** (note the `b'...'`).

| To get | Use |
|---|---|
| One string | `stdout.read().decode()` |
| A list of lines | `stdout.readlines()` |
| The error output | `stderr.read().decode()` |

## Password-Less Login with SSH Keys

Two ways to authenticate:

1. **Password-based**
2. **Key-based** (password-less): more secure, and nothing secret sits in the script

Generate a key pair on the machine that runs the scripts and copy the public key to the server:

```bash
mkdir -p ~/.ssh
ssh-keygen -t rsa -b 3072 -f ~/.ssh/id_rsa
ssh-copy-id ahmad@192.168.1.11
```

Then connect with `key_filename` instead of a password:

```python
import paramiko

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname="192.168.1.11", username="ahmad", key_filename="/root/.ssh/id_rsa")

stdin, stdout, stderr = client.exec_command("df -h")
print(stdout.read().decode())
client.close()
```

## Real-World Script: Filesystems Above 80%

Step by step:

1. Skip the header line: `lines[1:]`
2. Take the `Use%` column: `line.split()[4]`
3. Remove the `%` sign: `.replace("%", "")`
4. Compare as a number: `int(...) >= 80`

```python
import os
import paramiko

hostname = "192.168.1.11"
username = "ahmad"
password = os.environ["SSH_PASSWORD"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname=hostname, username=username, password=password)

stdin, stdout, stderr = client.exec_command("df -h")
for line in stdout.readlines()[1:]:
    usage = int(line.split()[4].replace("%", ""))
    if usage >= 80:
        print(line.strip("\n"))
client.close()
```

```text
/dev/loop1                 128K  128K     0 100% /snap/bare/5
/dev/loop0                  56M   56M     0 100% /snap/core18/2538
/dev/loop2                  62M   62M     0 100% /snap/core20/1593
/dev/loop3                  71M   71M     0 100% /snap/core22/275
```

Snap packages mount as read-only loop devices that are always 100% full, so a real check would also skip `/dev/loop*`.

## Connecting from Linux to Windows

1. On Windows: **Settings > Apps > Optional features**, add **OpenSSH Server**.
2. Run `services.msc` and start **OpenSSH SSH Server**.
3. Create a local user with `lusrmgr.msc`.
4. Connect exactly as before and run Windows commands such as `dir`.

## Project: Low-Memory Email Alert

Check the available memory on a server and send an email (topic 27) when it drops to 2 GB or less.

```python
import os
import smtplib
import paramiko
from datetime import date
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText

today = date.today().strftime("%B %d %Y")

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname="192.168.1.11", username="ahmad", password=os.environ["SSH_PASSWORD"])

stdin, stdout, stderr = client.exec_command("free -g | grep Mem | awk '{print $7}'")
available = stdout.read().decode().strip()
client.close()
print(available)

if int(available) <= 2:
    my_mail = "your.address@gmail.com"
    msg = MIMEMultipart()
    msg["Subject"] = f"ALERT : Memory available {available} GB on JBoss server at {today}"
    msg["From"] = my_mail
    msg["To"] = my_mail
    msg.attach(MIMEText("<html><b>Hi Team,</b><br>Please check the JBoss server memory.</html>", "html"))

    connection = smtplib.SMTP("smtp.gmail.com", 587)
    connection.starttls()
    connection.login(user=my_mail, password=os.environ["GMAIL_APP_PASSWORD"])
    connection.send_message(msg)
    connection.quit()
    print("Mail has been sent")
else:
    print("Everything is fine")
```

Example output when memory is low:

```text
1
Mail has been sent
```

`free -g | grep Mem | awk '{print $7}'` prints the **available** column of `free -g`. Run this script from cron (topic 28) every few minutes and you have a simple monitoring system.
