# 24. Reading and Writing Text Files

## Opening and Reading a File

```console
root@ahmadhassan:~/lect33# cat ahmad.txt; echo
My name is Ahmad Hassan
We are learning Python.
```

```python
# read1.py
file = open("ahmad.txt")
data = file.read()
print(data)
file.close()
```

```console
root@ahmadhassan:~/lect33# python3 read1.py
My name is Ahmad Hassan
We are learning Python.
```

Always close a file. The **`with`** statement closes it automatically, even if an error happens, so it's the recommended way:

```python
# read2.py
with open("ahmad.txt") as file:
    print(file.read())
```

```console
root@ahmadhassan:~/lect33# python3 read2.py
My name is Ahmad Hassan
We are learning Python.
```

## readlines(): A List of Lines

```python
# read3.py
with open("ahmad.txt") as file:
    data = file.readlines()
print(data)
for line in data:
    print(line.split())
```

```console
root@ahmadhassan:~/lect33# python3 read3.py
['My name is Ahmad Hassan\n', 'We are learning Python.']
['My', 'name', 'is', 'Ahmad', 'Hassan']
['We', 'are', 'learning', 'Python.']
```

## Absolute and Relative Paths

- An **absolute path** starts at the root: `/root/lect33/ahmad.txt`, or `C:\Users\Ahmad\Desktop\ahmad.txt` on Windows.
- A **relative path** is relative to the script's current working directory: `ahmad.txt`.

On Windows, write the path as a raw string so backslashes aren't treated as escapes:

```python
with open(r"C:\Users\Ahmad\Desktop\DevOps\Python\ahmad.txt") as file:
    print(file.read())
```

## File Modes

| Mode | Meaning |
|---|---|
| `"r"` | Read (the default). Error if the file doesn't exist |
| `"w"` | Write. Creates the file, or **erases** it if it exists |
| `"a"` | Append. Adds to the end, creating the file if needed |
| `"rb"` / `"wb"` | Read / write in **binary** mode (images, archives) |
| `"r+"` | Read and write |

These are all the same: `open("f.txt")`, `open("f.txt", "r")`, `open("f.txt", mode="r")`.

## Writing

A file opened for reading can't be written:

```python
# write_error.py
with open("ahmad.txt") as file:
    file.write("Ahmad Hassan")
```

```console
root@ahmadhassan:~/lect34# python3 write_error.py
Traceback (most recent call last):
  File "/root/lect34/write_error.py", line 2, in <module>
    file.write("Ahmad Hassan")
io.UnsupportedOperation: not writable
```

```python
# write.py
with open("ahmad.txt", "w") as file:
    file.write("Ahmad Hassan\n")
    file.write("This is the write command\n")
    file.write("Islamabad\n")
```

```console
root@ahmadhassan:~/lect34# python3 write.py
```

```console
root@ahmadhassan:~/lect34# cat ahmad.txt
Ahmad Hassan
This is the write command
Islamabad
```

`write()` doesn't add a new line, so add `\n` yourself.

## Appending

```python
# append.py
with open("ahmad.txt", "w") as file:
    file.write("We are learning Python from CloudOps")

with open("ahmad.txt", "a") as file:
    file.write("\nMy name is Ahmad Hassan")
```

```console
root@ahmadhassan:~/lect34# python3 append.py
```

```console
root@ahmadhassan:~/lect34# cat ahmad.txt; echo
We are learning Python from CloudOps
My name is Ahmad Hassan
```

```python

with open("ahmad.txt", "w") as file:
```

## Write vs Append in a Loop

Opening a file with `"w"` inside a loop erases it every time, so only the last line survives:

```python
# loop_write.py
for i in range(11):
    with open("ahmad.txt", "w") as file:
        file.write(f"Line : {i}\n")
```

```console
root@ahmadhassan:~/lect34# python3 loop_write.py
```

```console
root@ahmadhassan:~/lect34# cat ahmad.txt
Line : 10
```

```python
# loop_append.py
import os
os.remove("ahmad.txt")
for i in range(11):
    with open("ahmad.txt", "a") as file:
        file.write(f"Line : {i}\n")
```

```console
root@ahmadhassan:~/lect34# python3 loop_append.py
```

```console
root@ahmadhassan:~/lect34# cat ahmad.txt
Line : 0
Line : 1
Line : 2
Line : 3
Line : 4
Line : 5
Line : 6
Line : 7
Line : 8
Line : 9
Line : 10
```

Better still, open the file **once** before the loop.

## Binary Mode

```python
# binary.py
with open("data.bin", "wb") as file:
    file.write(b"\x00\x01Ahmad")

with open("data.bin", "rb") as file:
    print(file.read())
```

```console
root@ahmadhassan:~/lect34# python3 binary.py
b'\x00\x01Ahmad'
```
