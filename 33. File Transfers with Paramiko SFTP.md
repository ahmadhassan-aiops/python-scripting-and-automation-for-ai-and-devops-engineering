# 33. File Transfers with Paramiko SFTP

Paramiko also speaks **SFTP** (SSH File Transfer Protocol), so a script can upload, download and edit files on a remote server over the same secure connection.

Lab: the scripts run on a Windows laptop (192.168.1.7) and manage an Ubuntu server (192.168.1.11). Every example starts with the connection from topic 32:

```python
import os
import paramiko

hostname = "192.168.1.11"
username = "ahmad"
password = os.environ["SSH_PASSWORD"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname=hostname, username=username, password=password)

mysftp = client.open_sftp()
print(mysftp)
```

It prints a `paramiko.sftp_client.SFTPClient` object: the SFTP session is open.

## Common SFTP Operations

| Task | Code |
|---|---|
| Download (remote to local) | `mysftp.get("/home/ahmad/sample.csv", "sample.csv")` |
| Upload (local to remote) | `mysftp.put("test.csv", "/home/ahmad/test.csv")` |
| Change remote directory | `mysftp.chdir("/home/ahmad/lect51")` |
| List remote files | `mysftp.listdir()` |
| File details (size, owner, time) | `mysftp.stat("sample.csv")` |
| Read a remote file | `mysftp.open("test.csv").read()` |
| Append to a remote file | `mysftp.open("sample.csv", "a").write("ahmad hassan\n")` |
| Close | `mysftp.close()` then `client.close()` |

## Download a File

```python
import os
import paramiko

hostname = "192.168.1.11"
username = "ahmad"
password = os.environ["SSH_PASSWORD"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname=hostname, username=username, password=password)

mysftp = client.open_sftp()
mysftp.get("/home/ahmad/sample.csv", "sample.csv")
mysftp.close()
client.close()
```

## Upload a File into a Folder

```python
import os
import paramiko

hostname = "192.168.1.11"
username = "ahmad"
password = os.environ["SSH_PASSWORD"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

```

## Task: Daily Memory Log

Collect `free -g` from the remote server and **append** it to `Memory_details.txt` every day, like this:

```text
01 Oct 2022 13:30 and memory details are as below:
Available Memory : 2 GB
Total Memory : 10 GB
Used Memory : 8 GB
```

<details>
<summary><b>Solution</b></summary>

```python
import os
import datetime
import paramiko

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(hostname="192.168.1.11", username="ahmad", password=os.environ["SSH_PASSWORD"])

stdin, stdout, stderr = client.exec_command("free -g")
output = stdout.readlines()
client.close()

# Mem: total used free shared buff/cache available
memory = output[1].split()
total, used, available = memory[1], memory[2], memory[6]

now = datetime.datetime.now().strftime("%d %b %Y %H:%M")
report = (
    f"{now} and memory details are as below:\n"
    f"Available Memory : {available} GB\n"
    f"Total Memory : {total} GB\n"
    f"Used Memory : {used} GB\n\n"
)

with open("Memory_details.txt", "a") as file:
    file.write(report)

print("Memory details stored successfully!")
```

```console
root@ahmadhassan:~/lect51# python3 memory_log.py
Memory details stored successfully!
```

The **available** memory is column 7 of `free -g` (`memory[6]`), not the `free` column. Schedule the script with cron (`30 13 * * *`) to log once a day.
