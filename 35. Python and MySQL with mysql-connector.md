## Problem 1: root Can't Log In from Scripts

```python
mydb = mysql.connector.connect(host="localhost", user="root", password="...", database="cloudops")
```

```text
mysql.connector.errors.ProgrammingError: 1698 (28000): Access denied for user 'root'@'localhost'
```

On Ubuntu, MySQL's `root` uses **socket authentication**: it only works from the `root` Linux account with `sudo mysql`, not with a password. Create a dedicated user for your scripts instead. (Using `root` in scripts is bad practice anyway.)

## Create a User for Scripts

```sql
mysql> create user 'mysql_user'@'%' identified by '<strong-password>';
Query OK, 0 rows affected (0.00 sec)

mysql> select user,host from mysql.user;
+------------------+-----------+
| user             | host      |
+------------------+-----------+
| mysql_user       | %         |
| debian-sys-maint | localhost |
| mysql.session    | localhost |
| mysql.sys        | localhost |
| root             | localhost |
+------------------+-----------+
```

`'%'` means the user may connect from **any** host. Prefer a specific IP or subnet, such as `'mysql_user'@'192.168.1.%'`.

## Problem 2: Remote Connections Are Refused

By default MySQL only listens on `localhost`. To accept connections from other machines, edit `/etc/mysql/mysql.conf.d/mysqld.cnf`:

```text
bind-address = 0.0.0.0
```

```console
root@ahmadhassan:~# systemctl restart mysql
root@ahmadhassan:~# mysql -u mysql_user -h 192.168.1.8 -p
Enter password:
Welcome to the MySQL monitor.  Commands end with ; or \g.
mysql>
```

Also open port **3306** in the firewall, but only to the machines that need it.

## Problem 3: No Rights on the Database

```text
mysql.connector.errors.ProgrammingError: 1044 (42000): Access denied for user 'mysql_user'@'%' to database 'cloudops'
```

Grant the user what it needs on **this** database only:

```sql
mysql> grant select, insert, update, delete, create on cloudops.* to 'mysql_user'@'%';
mysql> flush privileges;
```

> Avoid `GRANT ALL PRIVILEGES ON *.* ... WITH GRANT OPTION`: it turns the script user into a full administrator of every database.

If you see an authentication plugin error with older clients, add `auth_plugin="mysql_native_password"` to `connect()`.

## Reading Data

The scripts read the password from an environment variable (`export MYSQL_PASSWORD='...'`):

```python
import os
import mysql.connector

mydb = mysql.connector.connect(
    host="192.168.1.8",
    user="mysql_user",
    password=os.environ["MYSQL_PASSWORD"],
    database="cloudops",
)
cur = mydb.cursor()

cur.execute("select * from trainer_details")
result = cur.fetchall()
for row in result:
    print(row)
mydb.close()
```

```text
(1, 'Ahmad', 'Hassan', 'Software Developer', 'ahmad', '<hash>', 1000, datetime.datetime(2022, 10, 1, 0, 0))
(2, 'Kazim', 'Shaikh', 'AVP', 'kazim', '<hash>', 5000, datetime.datetime(2022, 10, 1, 0, 0))
(4, 'Sarah', 'Shaikh', 'FD', 'sarah', '<hash>', 3000, datetime.datetime(2022, 10, 2, 0, 0))
```

| Method | Returns |
|---|---|
| `fetchall()` | Every row, as a list of tuples |
| `fetchone()` | The next row only |
| `fetchmany(n)` | The next `n` rows |

`cur.fetch()` doesn't exist; use one of the methods above.

## Inserting Data

Changes are saved only after **`commit()`**:

```python
import os
import mysql.connector

mydb = mysql.connector.connect(
    host="192.168.1.8",
    user="mysql_user",
    password=os.environ["MYSQL_PASSWORD"],
    database="cloudops",
)
cur = mydb.cursor()

sql = "insert into trainer_details (fname,lname,desig,username,password,salary,datetime) values (%s,%s,%s,%s,%s,%s,%s)"
cur.execute(sql, ("Ayesha", "Malik", "Blogger", "ayesha", "<hash>", 4000, "2022-10-02"))

# many rows at once
rows = [("Zara", "Khan", "SME", "zara", "<hash>", 8000, "2022-10-02")]
cur.executemany(sql, rows)
mydb.commit()
mydb.close()
```

### Always use placeholders

The `%s` placeholders let the connector quote each value safely. **Never** build SQL by joining strings:

```python
# DON'T: breaks on quotes, and allows SQL injection
sql = "update trainer_details set username=" + data + " where t_id=6"
```

With `data = "zara"`, MySQL reads `zara` as a column name:

```text
mysql.connector.errors.ProgrammingError: 1054 (42S22): Unknown column 'zara' in 'field list'
```

Wrapping the value in quotes by hand seems to fix it, but a value containing `'` breaks it again, and a crafted value such as `x' or '1'='1` could change every row. Pass the values separately instead:

```python
import os
import mysql.connector

mydb = mysql.connector.connect(
    host="192.168.1.8",
    user="mysql_user",
    password=os.environ["MYSQL_PASSWORD"],
    database="cloudops",
)
cur = mydb.cursor()

from datetime import datetime

now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
cur.execute(
    "insert into trainer_details (fname,lname,desig,username,password,salary,datetime) values (%s,%s,%s,%s,%s,%s,%s)",
    ("Ali", "Patel", "DevOps", "ali", "<hash>", 7000, now),
)
cur.execute("update trainer_details set desig=%s where t_id=%s", ("SME Lead", 6))
mydb.commit()

cur.execute("select * from trainer_details")
for row in cur.fetchall():
    print(row)
mydb.close()
```

```text
(1, 'Ahmad', 'Hassan', 'Software Developer', 'ahmad', '<hash>', 1000, datetime.datetime(2022, 10, 1, 0, 0))
(2, 'Kazim', 'Shaikh', 'AVP', 'kazim', '<hash>', 5000, datetime.datetime(2022, 10, 1, 0, 0))
(4, 'Sarah', 'Shaikh', 'FD', 'sarah', '<hash>', 3000, datetime.datetime(2022, 10, 2, 0, 0))
(5, 'Ayesha', 'Malik', 'Blogger', 'ayesha', '<hash>', 4000, datetime.datetime(2022, 10, 2, 0, 0))

```

## Deleting Data from User Input

```python
import os
import mysql.connector

try:
    name = input("Enter the first name to remove from MySQL: ")
    mydb = mysql.connector.connect(host="192.168.1.8", user="mysql_user",
                                   password=os.environ["MYSQL_PASSWORD"], database="cloudops")
    cur = mydb.cursor()
    cur.execute("delete from trainer_details where fname=%s", (name,))
    mydb.commit()
    print(cur.rowcount, "row(s) deleted")

    cur.execute("select * from trainer_details")
    for row in cur.fetchall():
        print(row)
    mydb.close()
except Exception as e:
    print("Something has an issue, please check your input:", e)
```
