`schedule` runs **functions**. You register a job, then keep calling `run_pending()` in a loop.

```python
import schedule
import time
from datetime import datetime

def job():
    print("Current time :", datetime.now())
    print("This is a test message via schedule")

schedule.every(10).seconds.do(job)

while True:
    schedule.run_pending()
    time.sleep(1)
```

## Scheduling Options

```python
schedule.every(10).seconds.do(job)
schedule.every(10).minutes.do(job)
schedule.every(5).hours.do(job)
schedule.every().day.at("21:03").do(job)          # every day at 9:03 PM
schedule.every().monday.do(job)                    # every Monday
schedule.every().sunday.at("06:00").do(job)        # every Sunday at 6:00 AM
schedule.every(5).weeks.do(job)
```

`schedule.every().day.at(...)` uses the **24-hour** clock.

## Project: a Scheduled Email Alert

Wrap the MIME email from topic 27 in a function and schedule it:

```python
import os
import time
import schedule
import smtplib
from datetime import datetime
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText

def send_alert():
    now = datetime.now()
    my_mail = "your.address@gmail.com"
    password = os.environ["GMAIL_APP_PASSWORD"]

    msg = MIMEMultipart()
    msg["Subject"] = f"Citrix connection alert {now:%B %d %Y} {now:%I:%M:%S %p}"
    msg["From"] = my_mail
    msg["To"] = my_mail
    msg.attach(MIMEText("<html><b>Hi Team,</b><br>This is a scheduled alert.</html>", "html"))

    connection = smtplib.SMTP("smtp.gmail.com", 587)
    connection.starttls()
    connection.login(user=my_mail, password=password)
    connection.send_message(msg)
    connection.close()
    print("Mail has been sent")

schedule.every().day.at("21:15").do(send_alert)

while True:
    schedule.run_pending()
    time.sleep(1)
```

```console
root@ahmadhassan:~/lect41# python3 myproject.py
Mail has been sent
```

The subject that arrives: `Citrix connection alert September 17 2022 09:15:00 PM`.

> An f-string can format a datetime directly: `f"{now:%B %d %Y}"` is the same as `now.strftime("%B %d %Y")`.

## Running Scripts with cron (Linux)

The `schedule` loop must keep running. For jobs that run at fixed times, **cron** is more reliable because the system starts the script for you:

```text
# minute hour day month weekday  command
1 * * * * /usr/bin/python3 /root/scripts/check.py           # minute 1 of every hour
10 0 * * * /usr/bin/python3 /root/scripts/archive_log.py    # every day at 00:10
```

Edit the table with `crontab -e` and list it with `crontab -l`.

## Running Scripts with Task Scheduler (Windows)

1. Find your Python path (for example `C:\python3\python.exe`) and your script path.
2. Create a batch file, `task.bat`:

```bat
@ECHO OFF
"C:\python3\python.exe" "C:\Users\Ahmad\Desktop\DevOps\Python\myproject.py"
EXIT
```

`@ECHO OFF` stops the batch file from printing each command (`ECHO` alone shows whether echo is on or off).

3. Open **Task Scheduler**, right-click **Create Task**, add a **Trigger** (when to run) and an **Action** (start `task.bat`).
