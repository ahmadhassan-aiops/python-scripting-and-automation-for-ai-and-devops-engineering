## Task 1

Fix the error below and print the variable.

```python
glass_of_water=12.ML
```

<details>
<summary><b>Solution</b></summary>

```python
# task1.py
glass_of_water = "12.ML"
print(glass_of_water)
```

```console
root@ahmadhassan:~/practice1# python3 task1.py
12.ML
```

`12.ML` isn't a valid number, so Python raises `SyntaxError: invalid decimal literal`. Quoting it makes it a string.

</details>

## Task 2

Add two numbers entered by the user and print the result.

<details>
<summary><b>Solution</b></summary>

```python
# task2.py
num1 = int(input("Enter number 1: "))
num2 = int(input("Enter number 2: "))
total = num1 + num2
print("The sum of {0} and {1} is {2}".format(num1, num2, total))
```

```console
root@ahmadhassan:~/practice1# python3 task2.py
Enter number 1: 10
Enter number 2: 20
The sum of 10 and 20 is 30
```

Avoid naming a variable `sum`: it hides the built-in `sum()` function.

</details>

## Task 4

Check whether a character is a vowel.

<details>
<summary><b>Solution</b></summary>

```python
# task4.py
ch = input("Please enter a character: ")
if ch.lower() in "aeiou":
    print("The given character", ch, "is a vowel")
else:
    print("The given character", ch, "is not a vowel")
```

```console
root@ahmadhassan:~/practice1# python3 task4.py
Please enter a character: o
The given character o is a vowel
```

`ch.lower() in "aeiou"` replaces ten `or` comparisons.

</details>

## Task 10

Insert a number at a chosen position in a list.

<details>
