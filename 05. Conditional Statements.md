# 05. Conditional Statements

A **condition** controls the flow of a program. It always evaluates to a Boolean: `True` or `False`.

## Comparison and Logical Operators

| Operator | Meaning | Example |
|---|---|---|
| `<` | Less than | `a < b` |
| `<=` | Less than or equal to | `a <= b` |
| `>` | Greater than | `a > b` |
| `>=` | Greater than or equal to | `a >= b` |
| `==` | Equal to | `a == b` |
| `!=` | Not equal to | `a != b` |
| `and` | Both conditions true | `a > b and b > c` |
| `or` | At least one condition true | `a > b or b > c` |
| `not` | Reverses the result | `not a > b` |

> Other languages write `&&`, `||` and `!`. Python uses the words **`and`**, **`or`** and **`not`**.

### Truth tables

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

## if

```python
if condition:
    statement
```

```python
# if_statement.py
a = 10
b = 2
if a > b:
    print("a is greater than b")
```


## if / elif / else

```python
# if_elif.py
a = int(input("Enter the a number: "))
b = int(input("Enter the b number: "))
c = int(input("Enter the c number: "))

if a > b and a > c:
    print(f"a is the biggest, a = {a}")
elif b > c and b > a:
    print(f"b is the biggest, b = {b}")
else:
    print(f"c is the biggest, c = {c}")
```

```console
root@ahmadhassan:~/lect7# python3 if_elif.py

```

## Nested if

An `if` inside another `if`:

```python
# nested_if.py
a = int(input("Enter the a number: "))
b = int(input("Enter the b number: "))
c = int(input("Enter the c number: "))

if a > b:
    if a > c:
        print(f"a is the biggest, a = {a}")
    else:
        print(f"c is the biggest, c = {c}")
else:
    if b > c:
        print(f"b is the biggest, b = {b}")
    else:
        print(f"c is the biggest, c = {c}")
```

```console
root@ahmadhassan:~/lect7# python3 nested_if.py
Enter the a number: 10
Enter the b number: 20
Enter the c number: 30
c is the biggest, c = 30
```

## Task: LinkedIn or Not

Read a number and print:

- **odd** number: `LinkedIn`
- **even** and between 2 and 5 (inclusive): `Not LinkedIn`
- **even** and between 6 and 20 (inclusive): `LinkedIn`
- **even** and greater than 20: `Not LinkedIn`
