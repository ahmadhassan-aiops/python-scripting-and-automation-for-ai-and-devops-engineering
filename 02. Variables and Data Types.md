# 02. Variables and Data Types

## Variables

A **variable** stores data in a program so you can refer to it later. Think of it as a label attached to a value.

```text
ali   --> 9876543210
name  --> Ahmad
```

```python
>>> name = "Ahmad"
>>> print(name)
Ahmad
>>> two = 2
>>> print(two)
2
>>> full_name = "Ahmad Hassan"
>>> print(full_name)
Ahmad Hassan
```

## Variables in a Script

A variable can be **reassigned** at any time; the latest value wins.

```python
# simple_variable.py
glass = "Empty"
print(glass)
print("The glass is : " + glass)

glass = "Full"
print("The glass is : " + glass)

glass = 'half-empty'
print("The glass is : " + glass)
```

```console
The glass is : Empty
The glass is : Full
The glass is : half-empty
```

## Reading Input from the User

`input()` shows a prompt and returns what the user types, always as a **string**.

```python
# user_input.py
name = input("Enter your name: ")
print("Your name is " + name)
```

```console
root@ahmadhassan:~/lect4# python3 user_input.py
Enter your name: Ahmad
Your name is Ahmad
```

## Naming Rules

| Variable name | Valid? | Why |
|---|---|---|
| `user_name` | Yes | Letters and underscores are allowed |
| `u` | Yes | A single letter is fine |
| `user1` | Yes | Digits are allowed after the first character |
| `user name` | No | Spaces are not allowed |
| `12` | No | A name cannot be only digits |
| `1user` | No | A name cannot start with a digit |

Names are **case sensitive**: `u` and `U` are different variables, so using `U` after defining `u` raises a `NameError`.

```python
>>> u = "ahmad"
>>> print("Your username is " + U)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'U' is not defined
```

## Length of a Value

`len()` counts characters in a string. It does not work on integers.

```python
>>> print(len("Ahmad"))
5
>>> print(len(786))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: object of type 'int' has no len()
```

## Data Types

A **data type** classifies a value.

| Type | Meaning | Example |
|---|---|---|
| `str` | Text | `"Ahmad Hassan"` |
| `int` | Whole number | `53` |
| `float` | Decimal number | `52.76894` |
| `bool` | True or False | `True` |

```python
# data_types.py
astring = "Ahmad Hassan"
aint = 53
afloat = 52.76894
abool = True

print(astring)
print(aint)
print(afloat)
print(abool)

print(type(astring))
print(type(aint))
print(type(afloat))
print(type(abool))
```

```console
root@ahmadhassan:~/lect4# python3 data_types.py
Ahmad Hassan
53
52.76894
True
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

## Input Is Always a String

Even when the user types a number, `input()` returns `str`. Convert it with `int()` or `float()`:

```python
# data_types_input.py
astring = input("Enter the string: ")
aint = int(input("Enter the integer: "))
afloat = float(input("Enter the float: "))

print(type(astring))
print(type(aint))
print(type(afloat))
```

```console
root@ahmadhassan:~/lect4# python3 data_types_input.py
Enter the string: Ahmad
Enter the integer: 54
Enter the float: 34.666
<class 'str'>
<class 'int'>
<class 'float'>
```

> `eval(input())` also converts input to a number, but it **executes** whatever the user types as Python code. Avoid it in real scripts; use `int()` or `float()` instead.
