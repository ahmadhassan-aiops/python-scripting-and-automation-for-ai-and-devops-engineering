# 29. Regular Expressions - findall and Character Classes

A **regular expression** (regex) is a sequence of characters that describes a **search pattern**. Regex is used everywhere in Unix and DevOps work: searching logs, validating input, extracting IP addresses and emails.

Python's regex functions live in the built-in **re** module:

| Function | Does | Topic |
|---|---|---|
| `findall()` | Returns every match as a list | 29, 30 |
| `finditer()` | Returns every match as a match object | 31 |
| `search()` | Finds the first match anywhere | 31 |
| `match()` | Matches only at the start of the string | 31 |
| `split()` | Splits a string by a pattern | 31 |
| `sub()` / `subn()` | Replaces matches | 31 |
| `compile()` | Pre-compiles a pattern for reuse | 31 |

## findall()

Syntax: `re.findall(pattern, text)`

```python
>>> import re
>>> myword = "Ahmad Hassan from Islamabad, We are learning Python and in this course we will learn two versions such as python2 and python3, We will learn Python selenium in this course"
>>> print(re.findall("We", myword))
['We', 'We']
>>> print(re.findall("Python2", myword))
[]
>>> print(re.findall("python2", myword))
['python2']
```

Patterns are **case sensitive**: `Python2` isn't in the text, so the result is an empty list.

## Character Sets: [ ]

Square brackets match **any one** of the characters inside.

```python
>>> print(re.findall("python[2]", myword))
['python2']
>>> print(re.findall("python[23]", myword))
['python2', 'python3']
>>> print(re.findall("[Pp]ython", myword))
['Python', 'python', 'python', 'Python']
>>> print(re.findall("python2|python3|Python", myword))
['Python', 'python2', 'python3', 'Python']
```

`|` means **or**.

## Special Sequences

```python
>>> myword = "Ahmad Hassan from Islamabad, ahmad.dev@example.com We are learning python2 and python3"
>>> print(re.findall(r"\d", myword))
['2', '3']
>>> print(re.findall(r"\w\w\w\w\w\w\w", myword))
['Islamab', 'example', 'learnin', 'python2', 'python3']
>>> print(re.findall(r"\W", myword))
[' ', ' ', ' ', ',', ' ', '.', '@', '.', ' ', ' ', ' ', ' ', ' ', ' ']
>>> print(re.findall(r"\s", myword)[:3])
[' ', ' ', ' ']
>>> print(re.findall(r"\S\S\S\S\S", myword)[:4])
['Ahmad', 'Hassa', 'Islam', 'abad,']
```

| Pattern | Matches |
|---|---|
| `\d` | A digit, 0-9 |
| `\D` | Anything except a digit |
| `\w` | A word character: a-z, A-Z, 0-9 and `_` |
| `\W` | Anything except a word character (spaces, `@`, `.`, `,`) |
| `\s` | Whitespace: space, tab, new line |
| `\S` | Anything except whitespace |
| `.` | Any single character except a new line |
| `\.` | A literal dot |

> Write patterns as **raw strings** (`r"\d"`). Without the `r`, Python itself tries to interpret the backslashes first.

## The Dot and the Escaped Dot

```python
>>> print(re.findall(r".", "Ah$%2@1"))
['A', 'h', '$', '%', '2', '@', '1']
>>> print(re.findall(r"\.\w\w\w", myword))
['.dev', '.com']
>>> print(re.findall(r"@\w\w\w\w\w\w\w\.\w\w\w", myword))
['@example.com']
```

## Anchors and Word Boundaries

```python
>>> text = "Python is a good language and this course is the best course"
>>> print(re.findall(r"course", text))
['course', 'course']
>>> print(re.findall(r"course$", text))
['course']
>>> print(re.findall(r"^Python", text))
['Python']
>>> print(re.findall(r"\bcourse", "in thiscourse and this course"))
['course']
>>> print(re.findall(r"\bcourse\b", "this course and these courses"))
['course']
>>> print(re.findall(r"\Bcourse\B", "thiscoursewe and this course"))
['course']
```

| Pattern | Matches |
|---|---|
| `^` | Start of the string |
| `$` | End of the string |
| `\b` | A word boundary (where a word starts or ends) |
| `\B` | Not a word boundary (inside a word) |

## Tabs and New Lines

```python
>>> text = "We will learn\tpython2\t\tand\nPython3"
>>> print(re.findall(r"\t", text))
['\t', '\t', '\t']
>>> print(re.findall(r"\n", text))
['\n']
```
