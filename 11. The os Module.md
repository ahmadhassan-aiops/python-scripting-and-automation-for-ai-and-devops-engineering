# 11. The os Module

The **os** module lets Python work with the operating system: files, folders, processes and environment, whether the machine runs Windows, macOS or Linux.

| Task | Windows command | Linux command |
|---|---|---|
| List files | `dir` | `ls` |
| Network details | `ipconfig` | `ifconfig` / `ip a` |

You must `import os` before using it:

```python
>>> os.getcwd()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'os' is not defined
```

## Current Directory: getcwd() and chdir()

```python
# os_module.py
import os
print("My old path is : " + os.getcwd())
os.chdir("/home")
print("My new path is : " + os.getcwd())
```

```console
root@ahmadhassan:~/lect16# python3 os_module.py
My old path is : /root/lect16
My new path is : /home
```

On Windows, use a path such as `"c:\\users"` in `chdir()`.

## Path Separator: os.sep

`os.sep` is `/` on Linux and `\\` on Windows, so scripts can build paths that work on both.

```python
# sep.py
import os
print(f"My path separator is {os.sep}")
```

```console
root@ahmadhassan:~/lect16# python3 sep.py
My path separator is /
```

## Creating, Renaming and Removing

```python
# mkdir.py
import os
os.mkdir("AH")
print(os.listdir())
os.rename("AH", "ah")
print(os.listdir())
os.rmdir("ah")
print(os.listdir())
open("temp.txt", "w").close()
os.remove("temp.txt")
print(os.listdir())
```

```console
root@ahmadhassan:~/lect16# python3 mkdir.py
['report.csv', 'AH', 'mkdir.py', 'listdir.py', 'sep.py', 'notes.txt', 'os_module.py']
['report.csv', 'mkdir.py', 'listdir.py', 'sep.py', 'ah', 'notes.txt', 'os_module.py']
['report.csv', 'mkdir.py', 'listdir.py', 'sep.py', 'notes.txt', 'os_module.py']
['report.csv', 'mkdir.py', 'listdir.py', 'sep.py', 'notes.txt', 'os_module.py']
```

| Function | Does |
|---|---|
| `os.mkdir(path)` | Creates one directory |
| `os.makedirs(path)` | Creates nested directories (`a/b/c`) |
| `os.rename(old, new)` | Renames a file or directory |
| `os.rmdir(path)` | Removes an **empty** directory |
| `os.remove(path)` | Deletes a file |

## User, Group and Process IDs

```python
# ids.py
import os
print("My path is : " + os.getcwd())
print("My current user ID : " + str(os.getuid()))
print("My current group ID : " + str(os.getgid()))
print("My current process ID : " + str(os.getpid()))
```

```console
root@ahmadhassan:~/lect16# python3 ids.py
My path is : /root/lect16
My current user ID : 0
My current group ID : 0
My current process ID : 1046
```

User ID `0` means **root**. `getuid()` and `getgid()` exist only on Linux and macOS; `getpid()` works everywhere.
