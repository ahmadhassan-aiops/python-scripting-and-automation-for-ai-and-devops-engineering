# 20. Functions

A **function** is a block of code that runs only when it is **called**. Functions are also called methods or procedures.

They break a program into small, modular pieces, avoid repetition and make code reusable.

## Syntax

```python
def function_name():
    statement

function_name()
```

```python
# first_function.py
def ahmad():
    print("Ahmad Hassan")
    print("Islamabad")

print("@@@@@@@@@@ This is the first call @@@@@@@@@@")
ahmad()
print("@@@@@@@@@@ This is the second call @@@@@@@@@@")
ahmad()
```

```console
@@@@@@@@@@ This is the first call @@@@@@@@@@
Ahmad Hassan
Islamabad
@@@@@@@@@@ This is the second call @@@@@@@@@@
Ahmad Hassan
Islamabad
```

## Naming Rules

| Name | Valid? |
|---|---|
| `def _ahmad()` | Yes |
| `def _ahmad_()` | Yes |
| `def ahmad1()` | Yes |
| `def ahmad1_hassan()` | Yes |
| `def 1ahmad()` | No: can't start with a digit |
| `def 123()` | No: can't be only digits |

## Types of Functions

1. **Built-in functions:** come with Python: `print()`, `input()`, `len()`, `os.system()`
2. **User-defined functions:** functions you write with `def`

## Parameters and Arguments

```python
# banner.py
def myban(text):
    print("*" * 30)
    print("\t" + text)
    print("*" * 30)

myban("This is an example function")
myban("This is a demo function")
```

```console
root@ahmadhassan:~/lect27# python3 banner.py

	This is an example function
******************************
******************************
	This is a demo function
******************************
```

- A **parameter** is the variable listed in the function definition (`text`).
- An **argument** is the value sent to the function when it's called (`"This is a demo function"`).

## Variable Scope: Local and Global

- A variable created **inside** a function is **local**: it exists only inside that function.
- A variable created **outside** every function is **global**: functions can read it.

```python
# scope.py
def first():
    ali = 1          # local, hides the global ali
    print("Inside first :", ali)

def second():
    print("Inside second:", ali)   # reads the global ali

ali = 2
first()
second()
print("Outside      :", ali)
```

```console
root@ahmadhassan:~/lect27# python3 scope.py
Inside first : 1
Inside second: 2
Outside      : 2
```

To **change** a global variable inside a function, declare it with `global`:

```python
# global_var.py
def change():
    global ali
    ali = 2
    print("Inside change:", ali)

ali = 1
change()
print("Outside      :", ali)
```

```console
root@ahmadhassan:~/lect27# python3 global_var.py
Inside change: 2
Outside      : 2
```

Passing the value as an argument is usually cleaner than `global`:

```python
# pass_value.py
def first(value):          # parameter
    print("My first function value is", value)

def second():
    ali = 2
    print("My second function value is", ali)
    first(ali)             # argument

second()
```

```console
root@ahmadhassan:~/lect27# python3 pass_value.py
My second function value is 2
My first function value is 2
```

## Returning Values

A function that only prints its result can't hand it back to the caller:

```python
# no_return.py

    c = a + b

def mycode():
    result = add(10, 20)
    print(result)

mycode()
```


Without `return`, a function returns `None`. Return the value instead:

```python

def add(a, b):
    return a + b

def mycode():

    b = int(input("Enter the second number: "))
    print(add(a, b))

mycode()
```

## Variable-Length Arguments: *args

`*args` collects any number of **positional** arguments into a tuple.

```python
# args.py
def server_info(*data):
    print(f"Server is : {data[0]}\nIP is : {data[1]}\nOS is : {data[2]}")

server_info("IBM", "192.168.1.1", "RHEL")

mylist = ["Dell", "192.168.1.2", "Ubuntu"]
server_info(*mylist)          # * unpacks the list into separate arguments

def show_types(*values):
    for v in values:
        print(type(v))

show_types(4, "five", 7.0)
```

```console
root@ahmadhassan:~/lect28# python3 args.py
Server is : IBM
IP is : 192.168.1.1
OS is : RHEL
Server is : Dell
IP is : 192.168.1.2
OS is : Ubuntu
<class 'int'>
<class 'str'>
<class 'float'>
```

## Keyword Arguments: **kwargs

`**kwargs` collects **named** arguments into a dictionary.

```python
# kwargs.py
def mycode(**mydata):
    for k, v in mydata.items():
        print(k, v)

mycode(server="IBM", IP="192.168.1.1", OS="AIX")

mydict = {"server": "HP", "IP": "192.168.1.5", "OS": "RHEL"}
mycode(**mydict)              # ** unpacks the dictionary
```

```console
IP 192.168.1.1
OS AIX
server HP
IP 192.168.1.5
OS RHEL
```

## Lambda Functions

A **lambda** is a small one-line function without a name: `lambda arguments: expression`.

```python
# lambda_demo.py
def add(ali, kazim):
    return ali + kazim
print(add(20, 10))

add = lambda ali, kazim: ali + kazim
print(add(20, 10))

bigger = lambda ali, kazim: ali if ali >= kazim else kazim
print(bigger(20, 10))
```

```console
root@ahmadhassan:~/lect28# python3 lambda_demo.py
30
30
20
```

## The `if __name__ == "__main__"` Guard

When you import a file, **all** its top-level code runs. The guard lets a file work both as a script and as an importable module.

```python
# Def_function.py (without the guard)
import os

def mycode():
    print("This is my code function")

print("My global print")
```

```python
# test.py
import Def_function
Def_function.mycode()
```

```console
root@ahmadhassan:~/lect28# python3 test.py
My global print
This is my code function
```

The global `print` ran during the import. Add the guard:

```python
# Def_function.py (with the guard)
import os

def mycode():
    print("This is my code function")

if __name__ == "__main__":
    print("My global print")
```

```console
root@ahmadhassan:~/lect28# python3 test.py
This is my code function
```

```console
root@ahmadhassan:~/lect28# python3 Def_function.py
My global print
```

`__name__` is `"__main__"` only when the file is run directly, not when it's imported.
