# 12. Running Shell Commands and Walking Directories

## os.walk(): Python's find Command

`os.walk(path)` visits a folder and every subfolder. For each one it gives a tuple of **(folder path, subfolders, files)**.

```console
root@ahmadhassan:~/lect17# tree
.
├── AH
│   ├── AH_sub
│   └── ah.txt
└── test.txt

3 directories, 2 files
```

```python
# os_walk.py
import os
print(list(os.walk(os.getcwd())))
```

```console
root@ahmadhassan:~/lect17# python3 os_walk.py
[('/root/lect17', ['AH'], ['os_walk.py', 'test.txt']), ('/root/lect17/AH', ['AH_sub'], ['ah.txt']), ('/root/lect17/AH/AH_sub', [], [])]
```

Topic 16 shows how to loop over this output.

## os.system(): Run a Command

`os.system()` runs a shell command and prints its output directly. It returns the command's **exit code**, not its output.

```python
# system.py
import os
code = os.system("ls")
print("Exit code:", code)
```

```console
root@ahmadhassan:~/lect17# python3 system.py
AH
os_walk.py
system.py
test.txt
Exit code: 0
```

## os.popen().read(): Capture the Output

To use a command's output in Python, read it with `os.popen()`:

```python
# popen.py
import os
mydata = os.popen("ls").read()
print(mydata.split())
```

```console
root@ahmadhassan:~/lect17# python3 popen.py
['AH', 'os_walk.py', 'popen.py', 'system.py', 'test.txt']
```

> For new scripts, the `subprocess` module is the modern choice: `subprocess.run(["ls"], capture_output=True, text=True).stdout`.

## Task: Print the OS Version

Print the operating system version in this format:

```text
My OS version is : 24.04.5 LTS
```

Solve it in two ways: with Linux commands, and with Python string methods.

<details>
<summary><b>Solution 1: Linux commands inside Python</b></summary>

The command on its own:

```console
root@ahmadhassan:~/lect17# cat /etc/os-release | grep -iw "version" | awk -F '=' '{print $2}' | awk '{print $1,$2}' | tr -d '"'
24.04.5 LTS
```

```python
# os_version.py
import os
cmd = "cat /etc/os-release | grep -iw \"version\" | awk -F '=' '{print $2}' | awk '{print $1,$2}' | tr -d '\"'"
myversion = os.popen(cmd).read().strip()
print(f"My OS version is : {myversion}")
```

```console
root@ahmadhassan:~/lect17# python3 os_version.py
My OS version is : 24.04.5 LTS
```

</details>

<details>
<summary><b>Solution 2: Python string methods</b></summary>

```python
# os_version2.py
import os
for line in os.popen("cat /etc/os-release").read().splitlines():
    if line.startswith("VERSION="):
        version = line.split("=")[1].strip('"')
        print(f"My OS version is : {' '.join(version.split()[:2])}")
```

```console
root@ahmadhassan:~/lect17# python3 os_version2.py
My OS version is : 24.04.5 LTS
```

</details>

## Task: Memory and Storage Report

Using `free -g` and `df -h` through `os.popen()`, print a report like this:

```text
Memory information:
Total memory is : <total> GB
Used memory is : <used> GB
Total swap memory is : <swap> GB

Storage details:
Root directory name is : /
Root directory total size : <size>
Root directory used size : <used>
```

<details>
<summary><b>Solution</b></summary>

```python
# report.py
import os
mem = os.popen("free -g").read().splitlines()
mem_line = mem[1].split()
swap_line = mem[2].split()
print("Memory information:")
print(f"Total memory is : {mem_line[1]} GB")
print(f"Used memory is : {mem_line[2]} GB")
print(f"Total swap memory is : {swap_line[1]} GB")

root = os.popen("df -h /").read().splitlines()[1].split()
print("\nStorage details:")
print(f"Root directory name is : {root[5]}")
print(f"Root directory total size : {root[1]}")
print(f"Root directory used size : {root[2]}")
```

```console
root@ahmadhassan:~/lect17# python3 report.py
Memory information:
Total memory is : 7 GB
Used memory is : 0 GB
Total swap memory is : 0 GB

Storage details:
Root directory name is : /
Root directory total size : 252G
Root directory used size : 17G
```

</details>
