# 01. Introduction to Python and Running Scripts

## What Is Python?

- Python is an **object-oriented** programming language.
- It is **platform independent**: the same script runs on Linux, Windows and macOS.
- It was created by **Guido van Rossum** and first released in 1991 (work started in 1989).
- Large companies use it every day, including NASA, Google, YouTube, Facebook and Instagram.

For DevOps and AI engineers, Python is the glue language: it automates servers, files, emails, databases and cloud tasks, and it is the main language of machine learning.

## Ways to Run Python

| Method | Command |
|---|---|
| Interactive shell | `python3` then type code at `>>>`, leave with `exit()` |
| Run a script | `python3 script.py` |
| Run as an executable | add a shebang line, `chmod +x script.py`, then `./script.py` |
| Run with a full path | `/root/lecture3/script.py` |

## Your First Script

```python
# simple.py
print("Ahmad Hassan")
```

```console
root@ahmadhassan:~/lecture3# python3 simple.py
Ahmad Hassan
```

Find where Python is installed:

```console
root@ahmadhassan:~/lecture3# which python3
/usr/bin/python3
```

## Running a Script Directly with a Shebang

The first line `#!/usr/bin/python3` (the **shebang**) tells Linux which interpreter runs the file, so you can execute it like a command. Use the path that `which python3` printed on your machine.

```python
#!/usr/bin/python3
print("Ahmad Hassan")
```

```console
root@ahmadhassan:~/lecture3# chmod +x simple.py && ./simple.py
Ahmad Hassan
```
