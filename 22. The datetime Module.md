# 22. The datetime Module

The **datetime** module works with dates and times: getting the current time, reading parts of a date, and calculating differences.

## Current Date and Time

```python
# now.py
import datetime

current_time = datetime.datetime.now()
print(current_time)
print(current_time.year)
print(current_time.month)
print(current_time.day)
print(current_time.weekday())
print(current_time.date())
print(current_time.time())
print(current_time.hour, current_time.minute, current_time.second)
print(current_time.microsecond)
print(current_time.ctime())
print(current_time.timetuple())
```

The default format is `yyyy-mm-dd hh:mm:ss.microseconds`. `weekday()` counts from Monday = 0 to Sunday = 6.

## Import Styles

The module and the class inside it are both called `datetime`, which causes a common mistake:

```python
# import_wrong.py
from datetime import datetime
print(datetime.datetime.now())
```

```console
root@ahmadhassan:~/lect31# python3 import_wrong.py
Traceback (most recent call last):
  File "/root/lect31/import_wrong.py", line 2, in <module>
    print(datetime.datetime.now())
AttributeError: type object 'datetime.datetime' has no attribute 'datetime'
```

```python
# import_right.py
from datetime import datetime
print(datetime.now())

import datetime as dt
print(dt.datetime.now())
```

```console
root@ahmadhassan:~/lect31# python3 import_right.py
2026-10-19 18:44:41.305145
2026-10-19 18:44:41.305231
```

| Import | Then call |
|---|---|
| `import datetime` | `datetime.datetime.now()` |
| `from datetime import datetime` | `datetime.now()` |
| `import datetime as dt` | `dt.datetime.now()` |

## Time Differences

Subtracting two datetimes gives a `timedelta`:

```python
# difference.py
from datetime import datetime

start_time = datetime.strptime("2:13:57", "%H:%M:%S")
end_time = datetime.strptime("11:47:52", "%H:%M:%S")
print(start_time)
print(end_time)

diff = end_time - start_time
print(diff)

sec = diff.total_seconds()
print("Difference in seconds :", sec)
print("Difference in minutes :", sec / 60)
print("Difference in hours   :", sec / 3600)
print("Days :", diff.days)
```

```console
root@ahmadhassan:~/lect31# python3 difference.py
1900-01-01 02:13:57
1900-01-01 11:47:52
9:33:55
Difference in seconds : 34435.0
Difference in minutes : 573.9166666666666
Difference in hours   : 9.565277777777778
Days : 0
```

When only a time is given, `strptime()` uses the date 1900-01-01.

## Time Zones

Install `pytz` (`pip install pytz`) to work with named time zones:

```python
# timezone.py
import pytz
from datetime import datetime

print(datetime.now())
pkt = pytz.timezone("Asia/Karachi")
print(datetime.now(pkt))
print(pkt)
```

```console
root@ahmadhassan:~/lect31# python3 timezone.py
2026-10-19 18:44:41.389319
2026-10-19 18:44:41.398387+05:00
Asia/Karachi
```

Since Python 3.9 the built-in `zoneinfo` module does the same: `datetime.now(ZoneInfo("Asia/Karachi"))`.
