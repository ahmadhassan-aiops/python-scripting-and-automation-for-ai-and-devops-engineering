# 17. break, continue and pass

| Statement | Effect |
|---|---|
| `break` | Exits the loop immediately |
| `continue` | Skips the rest of this round and moves to the next one |
| `pass` | Does nothing; a placeholder where code is required |

## break

```python
# break_while.py
i = 1
while True:
    print(i)
    i = i + 1
    if i >= 5:
        break
```

```console
root@ahmadhassan:~/lect25# python3 break_while.py
1
2
3
4
```

`while True` would run forever; `break` is what stops it.

```python
# break_for.py
for i in range(1, 10):
    if i == 5:
        break
    print(i)
```

```console
root@ahmadhassan:~/lect25# python3 break_for.py
1
2
3
4
```

## continue

```python
# continue.py
for i in range(1, 10):
    if i == 5:
        continue
    print(i, end=" ")
print()
```

```console
root@ahmadhassan:~/lect25# python3 continue.py
1 2 3 4 6 7 8 9
```

Only 5 is skipped.

## pass

A block can't be empty. This is an error:

```python
# pass_error.py
for i in range(1, 10):
    if i == 5:
```

```console
root@ahmadhassan:~/lect25# python3 pass_error.py
  File "/root/lect25/pass_error.py", line 2
    if i == 5:
IndentationError: expected an indented block after 'if' statement on line 2
```

Use `pass` as a placeholder for code you'll write later, inside loops, functions, classes or `if` statements:

```python
# pass_ok.py
for i in range(1, 10):
    if i == 5:
        pass
    print(i, end=" ")
print()
```

```console
root@ahmadhassan:~/lect25# python3 pass_ok.py
1 2 3 4 5 6 7 8 9
```

Unlike `continue`, `pass` does not skip anything: 5 is still printed. And any code after `break` in the same block never runs.
