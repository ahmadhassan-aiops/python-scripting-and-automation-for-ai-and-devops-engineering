# 21. Exception Handling

## Three Kinds of Errors

| Error | When | Can you handle it with try? |
|---|---|---|
| **Syntax error** | The code breaks Python's grammar | No: the script doesn't start |
| **Logic error** | The code runs but gives the wrong answer | No: fix the logic |
| **Runtime error (exception)** | Something goes wrong while running | **Yes** |

### Syntax error

```python
# syntax.py
print("Ahmad Hassan"
```

```console
root@ahmadhassan:~/lect30# python3 syntax.py
  File "/root/lect30/syntax.py", line 1
    print("Ahmad Hassan"
SyntaxError: '(' was never closed
```

### Logic error

This code runs, but prints the wrong answer when both numbers are equal:

```python
# logic.py
a = 100
b = 100
if a > b:
    print("a is big")
else:
    print("b is big")
```

```console
root@ahmadhassan:~/lect30# python3 logic.py
b is big
```

Fix it by handling the equal case:

```python
if a > b:
    print("a is big")
elif a == b:
    print("Both a and b are the same")
else:
    print("b is big")
```

## Exceptions

An **exception** is an error raised while the program runs. Python stops the script unless you **handle** it with `try` and `except`:

```python
try:
    code that might fail
except:
    what to do if it fails
```

### NameError

```python
# name_error.py
x = "AH"
print("My value is", x)
print("My value is", y)
```

```console
root@ahmadhassan:~/lect30# python3 name_error.py
My value is AH
Traceback (most recent call last):
  File "/root/lect30/name_error.py", line 3, in <module>
    print("My value is", y)
NameError: name 'y' is not defined
```

```python
# name_error_handled.py
try:
    x = "AH"
    print("My value is", x)
    print("My value is", y)
except Exception as e:
    print("Something has an issue:", e)
```

```console
root@ahmadhassan:~/lect30# python3 name_error_handled.py
My value is AH
Something has an issue: name 'y' is not defined
```

`except Exception as e` stores the error so you can print its message.

## Handling Each Exception Separately

| Exception | Example message |
|---|---|
| `NameError` | name 'y' is not defined |
| `IndexError` | list index out of range |
| `ModuleNotFoundError` | No module named 'osss' |
| `ZeroDivisionError` | division by zero |
| `ValueError` | invalid literal for int() with base 10: 'ten' |
| `TypeError` | can only concatenate str (not "int") to str |

Give each one its own message. Python checks the `except` blocks **in order** and runs the first that matches, so the general `Exception` goes **last**.

```python
# ex_handle.py
import os
try:
    x = "AH"
    print("My value is " + x)
    mylist = [2, 7, 8, 9]
    print(mylist[3])
    os.system("hostname")
    a = int(input("Enter the number: "))
    b = int(input("Enter the number: "))
    print(a / b)
except NameError:
    print("Your variable has an issue, please check it is defined")
except IndexError:
    print("Please check your index; it must be within range")
except ModuleNotFoundError:
    print("Please check the module name or whether it is installed")
except ZeroDivisionError:
    print("You can't divide a number by zero")
except ValueError:
    print("Value error: you can't divide a number by a string")
except Exception as e:
    print("Something has an issue in your code:", e)
else:
    print("This is the else block")
finally:
    print("This statement prints no matter what")
```

## else and finally

| Block | Runs when |
|---|---|
| `try` | Always first |
| `except` | Only if an exception happened |
| `else` | Only if **no** exception happened |
| `finally` | **Always**, success or failure: the place to close files and connections |
