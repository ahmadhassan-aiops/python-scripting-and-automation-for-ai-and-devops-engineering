# 34. MySQL Setup and SQL Basics

Automation scripts often store their results in a database so they can be queried, graphed and compared over time. This topic sets up **MySQL** on Ubuntu and covers the SQL you need; topic 35 drives it from Python.

You need an Ubuntu machine: a VM in VirtualBox, a cloud instance, or WSL.

## Install MySQL Server

```console
root@ahmadhassan:~# apt-get update
root@ahmadhassan:~# apt-get install mysql-server
root@ahmadhassan:~# systemctl status mysql.service
root@ahmadhassan:~# systemctl enable mysql.service
root@ahmadhassan:~# systemctl start mysql.service
root@ahmadhassan:~# mysql_secure_installation
```

`mysql_secure_installation` sets the root password policy, removes anonymous users and the test database, and disables remote root login.

## Create a Table

We'll keep trainer records in a table called `trainer_details`:

| Column | Type | Notes |
|---|---|---|
| `t_id` | `int` | Primary key, numbered automatically |
| `fname`, `lname`, `desig` | `char(255)` | First name, last name, designation |
| `username` | `varchar(255)` | |
| `password` | `varchar(255)` | Store a **hash**, never the plain password |
| `salary` | `int` | |
| `datetime` | `datetime` | When the record was added |

A table must belong to a database. Without `use`, MySQL complains:

```sql
mysql> create table trainer_details
(
t_id int NOT NULL AUTO_INCREMENT,
fname char(255),
lname char(255),
desig char(255),
username varchar(255),
password varchar(255),
salary int,
datetime datetime,
PRIMARY KEY (t_id)
);
ERROR 1046 (3D000): No database selected
```

```sql
mysql> use cloudops;
Database changed
mysql> create table trainer_details
(
t_id int NOT NULL AUTO_INCREMENT,
fname char(255),
lname char(255),
desig char(255),
username varchar(255),
password varchar(255),
salary int,
datetime datetime,
PRIMARY KEY (t_id)
);
Query OK, 0 rows affected (0.03 sec)

mysql> show tables;
+--------------------+
| Tables_in_cloudops |
+--------------------+

+--------------------+
```

## Changing the Table: ALTER

```sql
mysql> alter table trainer_details add column email varchar(255);
Query OK, 0 rows affected (0.06 sec)

mysql> alter table trainer_details drop column email;
Query OK, 0 rows affected (0.09 sec)

mysql> alter table trainer_details add email varchar(255) after password;
Query OK, 0 rows affected (0.09 sec)
```

| Statement | Does |
|---|---|
| `alter table t add column c type;` | Adds a column at the end |
| `alter table t add c type after x;` | Adds a column after column `x` |
| `alter table t drop column c;` | Removes a column |

## Update and Delete

```sql
mysql> update trainer_details set password='<new-hash>' where t_id=3;
Query OK, 1 row affected (0.01 sec)
Rows matched: 1  Changed: 1  Warnings: 0

mysql> delete from trainer_details where t_id=3;
Query OK, 1 row affected (0.01 sec)
```

> Always include a **WHERE** clause with `update` and `delete`. Without it, every row in the table changes or disappears.

After deleting row 3 and inserting a new row, the new row gets `t_id` **4**, not 3: `AUTO_INCREMENT` never reuses numbers.

```sql
mysql> select * from trainer_details;
```
