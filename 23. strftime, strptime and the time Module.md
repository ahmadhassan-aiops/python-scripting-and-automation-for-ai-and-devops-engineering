# 23. strftime, strptime and the time Module

| Function | Converts |
|---|---|
| `strftime()` | datetime object **to a string** ("f" for format) |
| `strptime()` | string **to a datetime** object ("p" for parse) |

## strftime(): Your Own Date Format

```python
# strftime_demo.py
from datetime import datetime

current = datetime.now()
print(current, type(current))

year = current.strftime("%Y")
print("My year is", year, type(year))
print("My month is", current.strftime("%m"))
print("My day is", current.strftime("%d"))
print("My time is", current.strftime("%H:%M:%S"))

print(current.strftime("%d/%m/%Y"))
print(current.strftime("%d-%m-%Y"))
print(current.strftime("%d/%m/%Y %H:%M:%S"))
print(current.strftime("%A %m %y"))
print(current.strftime("%d/%m/%Y %I:%M:%S %p"))
print(datetime.strftime(current, "%Y/%m/%d"))
```

```console
My year is 2026 <class 'str'>
My month is 10

19-10-2026
19/10/2026 18:44:41
```

> Use `%I` (12-hour clock) with `%p` (AM/PM). `%H` with `%p` would print something like `16:24 PM`.

### Format codes

| Code | Example | Meaning |
|---|---|---|
| `%a` / `%A` | Sun / Sunday | Weekday name, short / full |
| `%d` | 08 | Day of the month |
| `%b` / `%B` | Sep / September | Month name, short / full |
| `%m` | 09 | Month as a number |
| `%y` / `%Y` | 13 / 2013 | Year without / with century |
| `%H` | 07 | Hour, 24-hour clock |
| `%I` | 07 | Hour, 12-hour clock |
| `%p` | AM | AM or PM |
| `%M` | 06 | Minute |
| `%S` | 05 | Second |
| `%f` | 000000 | Microsecond |
| `%z` / `%Z` | +0500 / PKT | UTC offset / time zone name |
| `%j` | 251 | Day of the year |
| `%U` / `%W` | 36 | Week number (Sunday / Monday first) |
| `%c` | Sun Sep 8 07:06:05 2013 | Locale date and time |
| `%x` / `%X` | 09/08/13 / 07:06:05 | Locale date / time |
| `%%` | % | A literal percent sign |

On Linux, `%-d`, `%-m` and `%-I` remove the leading zero. Full reference: https://strftime.org

## strptime(): Parse a String

```python
# strptime_demo.py
from datetime import datetime

mydate = "2022/09/05 13:20:52"
print(type(mydate))
parsed = datetime.strptime(mydate, "%Y/%m/%d %H:%M:%S")
print(parsed)
print(type(parsed))
```

## The time Module

`time.time()` returns the number of seconds since 1 January 1970 (the **Unix epoch**).

```python
# time_demo.py
import time
import datetime

seconds = time.time()
print(seconds)
print(datetime.datetime.fromtimestamp(seconds))
print(time.ctime(seconds))
print(time.gmtime())
print(time.localtime())
print(time.strftime("%m/%d/%Y, %H:%M:%S"))
```

```console
root@ahmadhassan:~/lect32# python3 time_demo.py
1792417481.5242562
2026-10-19 18:44:41.524256
Mon Oct 19 18:44:41 2026
time.struct_time(tm_year=2026, tm_mon=10, tm_mday=19, tm_hour=13, tm_min=44, tm_sec=41, tm_wday=0, tm_yday=292, tm_isdst=0)
time.struct_time(tm_year=2026, tm_mon=10, tm_mday=19, tm_hour=18, tm_min=44, tm_sec=41, tm_wday=0, tm_yday=292, tm_isdst=0)
10/19/2026, 18:44:41
```

`gmtime()` is UTC; `localtime()` uses the machine's time zone.

## File Creation Time

`os.path.getctime()` returns a timestamp; convert it to a readable date:

```python
# file_time.py
import os
import datetime

stamp = os.path.getctime("/root/lect32/ah.csv")
print(stamp)
print(datetime.datetime.fromtimestamp(stamp))
```

### Search for a file and show its time

```python
# search_file_time.py
import os
import datetime

find_file = input("Enter the search: ")
for root, dirs, files in os.walk("/root/lect32/"):
    for name in files:
        if name == find_file:
            mypath = os.path.join(root, name)
            created = datetime.datetime.fromtimestamp(os.path.getctime(mypath))
            print(f"We found the file {mypath}, its time is : {created}")
```

