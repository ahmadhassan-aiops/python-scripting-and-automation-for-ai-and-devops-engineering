# 19. List and Dictionary Comprehensions

A **comprehension** builds a list, set or dictionary in one readable line.

```python
new_list = [expression for item in iterable if condition]
new_dict = {key: value for (key, value) in iterable if condition}
new_set  = {expression for item in iterable if condition}
```

Each example below shows the loop version first, then the comprehension.

## Filtering a List

```python
# files_loop.py
myfiles = ["ahmad.txt", "abc.csv", "test.txt", "ali.txt", "ahmad.csv"]
newfiles = []
for name in myfiles:
    if "a" in name:
        newfiles.append(name)
print(newfiles)
```

```python
# files_comp.py
myfiles = ["ahmad.txt", "abc.csv", "test.txt", "ali.txt", "ahmad.csv"]
print([name for name in myfiles if name != "ahmad.csv"])
print([name.upper() for name in myfiles if name != "ahmad.csv"])
```

## Filtering Nested Lists

```python
# salary_list.py
salary = [
    ["Ahmad", 20000],
    ["Ali", 30000],
    ["Kazim", 25000],
    ["Ayesha", 50000],
    ["Sarah", 27000],
]

for person in salary:
    if person[1] >= 30000:
        print(person)

print([person for person in salary if person[1] >= 30000])

print([p for p in salary if p[0].lower().startswith("a") and p[1] >= 25000])
```

```console
['Ayesha', 50000]
[['Ali', 30000], ['Ayesha', 50000]]
[['Ali', 30000], ['Ayesha', 50000]]
```

## Building a List of Numbers

```python
# even.py
even_num = []
for i in range(11):
    if i % 2 == 0:
        even_num.append(i)
print(even_num)

print([i for i in range(11) if i % 2 == 0])
```

## Set and Dictionary Comprehensions

```python
# salary_dict.py
salary = {"Ahmad": 20000, "Ali": 40000, "Kazim": 25000, "Ayesha": 50000, "Sarah": 27000}

names = {k for (k, v) in salary.items() if 20000 <= v <= 30000}
print(type(names), sorted(names))

mid = {k: v for (k, v) in salary.items() if 20000 <= v <= 30000}
print(mid)
```

```console
root@ahmadhassan:~/practice2# python3 salary_dict.py
<class 'set'> ['Ahmad', 'Kazim', 'Sarah']
{'Ahmad': 20000, 'Kazim': 25000, 'Sarah': 27000}
```

- Curly braces with **only a value** (`{k for ...}`) build a **set**, which has no order, so it's sorted here for a stable display.
- Curly braces with **key: value** build a **dictionary**.
- `20000 <= v <= 30000` is Python's chained comparison, the same as `v >= 20000 and v <= 30000`.
