# 14. The platform Module

The **platform** module shows system information, much like the Linux `uname` command:

| Linux command | Shows |
|---|---|
| `uname` | Operating system |
| `uname -m` | Architecture |
| `uname -r` | Kernel release |
| `uname -a` | Everything |

```python
# os_plat.py
import platform
print("System       :", platform.system())
print("Node         :", platform.node())
print("Release      :", platform.release())
print("Machine      :", platform.machine())
print("Architecture :", platform.architecture())
print("Python       :", platform.python_version())
```

```console
root@ahmadhassan:~/lect20# python3 os_plat.py

Node         : ahmadhassan
Release      : 6.18.44-fc-v139
Machine      : x86_64
Architecture : ('64bit', 'ELF')
Python       : 3.13.16
```

On a Windows laptop, `platform.system()` prints `Windows` and `platform.processor()` prints something like `Intel64 Family 6 Model 142 Stepping 12, GenuineIntel`.

Other functions: `platform.platform()` (one-line summary), `platform.processor()` and `platform.uname()` (all fields, like `uname -a`).

## One Script for Every OS

Use `platform.system()` to run the right command on each operating system:

```python
# network.py
import os
import platform

if platform.system() == "Windows":
    os.system("ipconfig")
elif platform.system() == "Linux":
    os.system("hostname -I")
else:
    print("Sorry, please check with the admin")
```

```console
root@ahmadhassan:~/lect20# python3 network.py
192.0.2.2
```
