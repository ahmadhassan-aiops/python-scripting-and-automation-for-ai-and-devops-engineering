# 08. Tuples

A **tuple** stores several items in one variable, like a list, but it is written with parentheses and is **immutable**: once created, it can't be changed. Tuples use less memory than lists and protect data from accidental changes.

```python
>>> data = (1, 3, 7)
>>> print(data)
(1, 3, 7)
>>> print(type(data))
<class 'tuple'>
```

## A One-Item Tuple Needs a Comma

```python
>>> data = (1)
>>> print(type(data))
<class 'int'>
>>> data = (1,)
>>> print(type(data))
<class 'tuple'>
```

## Indexing, Nesting and Slicing

```python
>>> data = (1, 3, 7, [9, 5, 6], 7, 2)
>>> print(data[1])
3
>>> print(data[3])
[9, 5, 6]
>>> print(data[3][1])
5
>>> print(data[-1])
2
>>> print(data[1:4])
(3, 7, [9, 5, 6])
>>> print(data[:-2])
(1, 3, 7, [9, 5, 6])
>>> print(data[::-1])
(2, 7, [9, 5, 6], 7, 3, 1)
```

## Immutability

You can't change, or delete, an item of a tuple. But a **list inside** a tuple can still be changed, because the tuple only stores a reference to it.

```python
>>> data[1] = "AH"
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
>>> del data[0]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object doesn't support item deletion
>>> data[3][1] = "AH"
>>> print(data)
(1, 3, 7, [9, 'AH', 6], 7, 2)
```

## Converting, Deleting and Checking

```python
>>> print(tuple([1, 5, 1, 23]))
(1, 5, 1, 23)
>>> print(bool(()))
False
>>> print(bool((3, 5, 6)))
True
>>> t = (1, 5, 6, 9)
>>> del t
>>> print(t)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 't' is not defined
```

An **empty** tuple is `False`; any tuple with items is `True`. This is a common interview question.

## Nested Tuples

```python
>>> my_tuple = ("AH", [8, 5, 4], (1, 4, 5))
>>> print(my_tuple[0])
AH
>>> print(my_tuple[1][1])
5
>>> print(my_tuple[2][2])
5
```

## Tuple Functions and Methods

```python
>>> t = (5, 6, 78, 98, 5, 7, 5)
>>> print(len(t))
7
>>> print(t.count(5))
3
>>> print(t.index(5))
0
>>> print(t.index(5, 1))
4
>>> print(t.index(5, 5))
6
>>> print(min(t), max(t), sum(t))
5 98 204
>>> print((1, 5, 8) + (6, 7))
(1, 5, 8, 6, 7)
>>> print(("ahmad",) * 2)
('ahmad', 'ahmad')
```

`index(value, start)` searches from position `start`, so `t.index(5, 1)` finds the second 5 at position 4.
